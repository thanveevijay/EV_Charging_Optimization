# Privacy Guidelines

- Do not commit raw session exports unless the dataset license explicitly permits redistribution.
- Remove names, email addresses, account identifiers, and other direct identifiers from analysis datasets.
- Treat timestamps and station identifiers as potentially sensitive when they can be linked to individuals.
- Prefer aggregated station-hour statistics for public visualizations.
- Keep local data paths and credentials out of source files.
- Document the provenance and permitted use of each dataset.

The public repository should contain code and small synthetic fixtures rather than private operational records.
