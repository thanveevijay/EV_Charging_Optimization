# Research Questions

1. Does graph-based state representation improve scheduling outcomes over a flat state representation?
2. How does forecast information affect queueing and peak load?
3. What trade-offs emerge between waiting time and energy fulfillment?
4. How sensitive are outcomes to reward weights and simulation time resolution?
5. Does the learned policy generalize across stations and time periods?

Each question should map to a pre-defined experiment and evaluation metric. Avoid selecting only favorable runs for reporting.
